# 静心木鱼 V1.6 · 触控跟手版

一个可直接部署到 GitHub Pages 的单文件电子木鱼网页，专门针对 iPhone Safari 高频连击的视觉表现优化。

## 文件

- `index.html`：**唯一必需文件**，已经包含木鱼、木槌素材、敲击音效、成就与 JavaScript。
- `assets/mallet.svg`：木槌重新绘制的 SVG **编辑源稿**，不需要单独上传也能运行。
- `assets/mallet_3x.webp`：由矢量源稿预渲染的 3 倍尺寸 WebP，已内嵌到 HTML，无需单独请求。

## V1.6 对比 V1.5

- **敲击动画**：由「每次重新播放 WAAPI 关键帧」改为「按下即下击、松手自动回弹」的 CSS `transform` 过渡。
- **反复连击**：动画自动从当前中间姿态向新目标运动，不再重置回第一帧。
- **动画素材**：木槌重新画成低复杂度矢量图形，部署时预渲染为透明 WebP 静态贴图；木鱼保留原有木纹图像。
- **主线程负担**：没有逐帧 JavaScript 计算，也不再使用独立的木槌、木鱼和光圈 WAAPI 实例；仅留下固定数量的 `+1` 文字实例。
- **保留**：既有 Safari 音效实现、防双击缩放、今日和累计统计、功德称号、localStorage 存档，以及「禅」字品牌图标。

## 部署到 GitHub Pages

上传根目录的 `index.html`，在 GitHub 仓库 `Settings > Pages` 中开启 `Deploy from a branch`，分支选择 `main`，路径 `/ (root)`。

更新已部署的网站后，建议用 `?v=16` 作为缓存规避参数。

## 测试注意事项

已经在 Chromium 的 320 / 375 / 390px 手机触摸模拟环境测试触控按压、松手回弹和连击计数（25 次）；额外测试 100 次敲击、第一阶成就解锁和 10 阶列表，未发现 JavaScript 报错或页面缩放。

**尚未在真实 iPhone Safari 上验证具体 FPS 或连续点击延迟。** 若仍有卡顿，建议分别测试开启与关闭音效，并记录 iOS 版本和手机型号，以排除 HTMLAudioElement 播放造成的主线程开销。
