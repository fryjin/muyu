# 静心木鱼（v1.2 · 古寺竹影）

静态单文件网页，适用于 GitHub Pages / iPhone Safari / 桌面浏览器。

## 使用与部署

将 `index.html` 上传至 GitHub 仓库根目录，在 **Settings → Pages** 启用 `main` 分支、根目录发布。

## 功能

- 浅青与米白宣纸感背景、竹影与远山古寺剪影，降低黑屏带来的反光观感（物理反光无法完全消除）。
- 木鱼点击动画、快速连击 +1 浮字、音效开关。
- 原有 v1.1 音效实现完全保留；iPhone 静音模式下如无声，请关闭静音并检查媒体音量。
- 今日敲击计数、历史累计计数使用原有 `zen-woodfish-v1` 本地存储键，覆盖更新不会主动丢失旧记录。
- 十阶**每日成就**：100、500、1000、2000、3000、5000、8000、12000、20000、30000 次。
- 主界面展示当前称号及下一阶进度；点击成就卡查看全部等级。
- 达成门槛时显示解锁提示；每日 00:00 按设备本地时间重置今日称号，累计敲击保持不变。
- 支持 iPhone Safari：防误触放大、安全区域、底部清单可滚动。

## 注意

纯前端，无服务器。所有敲击记录存于当前设备的浏览器 `localStorage`，不跨设备同步。切换域名、浏览器或清理站点数据可能导致记录不一致或丢失。
