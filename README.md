# 静心木鱼 · V1.4 流畅敲击版

基于 V1.3.1 的单文件静态网站。古寺竹影界面、iPhone Safari 防双击缩放、10 阶今日成就、音效及存档均保留。

## 快速部署

将 `index.html` 上传至 GitHub 仓库根目录并启用 **Settings → Pages → Deploy from a branch → main / (root)**。

更新已发布页面后，可用 `?v=14` 访问新资源，防止 Safari 复用旧页面缓存。

## V1.4 动画更新

- **单一 RAF 时钟**：一个 `requestAnimationFrame` 驱动木槌、木鱼和敲击波纹，无需每次点击重新创建/取消两段 WAAPI 动画。
- **可中断的动作衔接**：新一击从上一帧角度继续；若木槌仍处于下击位置，先快速提槌再下击，避免快速连点时动作“粘”在最低点。
- **短行程反馈**：下击约 27ms，回弹约 110–170ms（帧率不同会有差异）。木鱼只做轻微形变，减少夸张抖动；加入低对比度的涟漪。
- **浮字对象池**：只复用 10 个“功德 +1”节点，不再高频增删 DOM 和开启清理定时器；超过 10 个时循环复用。
- **降低主线程负载**：累计次数与成就 UI 以 RAF 合并刷新，每帧最多绘制一次；本地保存采用间隔合并，退出页面时仍立即保存。
- **GPU 友好**：移动图片只改变 `transform`；去掉移动图片上的 `filter: drop-shadow`，保留静态地面阴影。

## 未修改的部分

- 沿用 V1.3.1 的敲击音效，包括 iPhone Safari 的媒体音轨。
- 沿用 V1.3.1 的 `touchstart` / `touchend` / `click` 防重复计数与防双击缩放策略。
- 沿用原来的 `localStorage` 键 `zen-woodfish-v1`，更新页面不会主动清除历史数据。
- 今日成就依旧于当地日期变更后重置，累计次数不受影响。

## 测试范围

在 Chromium 的 iPhone 13 / iPhone SE 屏幕及触控模拟下，101 次连续触摸均计数成功；第 100 次成就正确触发，10 阶列表正常，未发现 JavaScript 错误。**真实 iOS Safari 上的帧率及音频体验需在实体手机复核**。
